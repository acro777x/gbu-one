# Follow-up prompts

Paste after the first build. Change one thing at a time.

**Looks generic or AI-made**
"Review the page as a critical designer. List the 5 most template-looking choices, replace each with something specific to GBU students, and show only the changed code."

**Phone problems**
"Test mentally at 360px and 390px. List anything that overflows, is under 44px to tap, or is cramped. Fix and show only changed code."

**Too heavy**
"Cut the file under 60 KB before images. Remove unused CSS, merge duplicate rules, inline only needed SVG."

**Copy is stiff**
"Rewrite all text so a final-year student would say it aloud. Shorter sentences. Remove any sentence that does not carry a fact."

**Stronger hero**
"Give me three alternative hero headlines and sub-lines, each leading with a different student problem (room changes, exam dates, past papers). Do not change the layout."

**School picker polish**
"Make the school picker the best moment on the page: keyboard accessible, announces the selected school to screen readers, avatar swap with no layout shift, accent applied to the phone, chips and section only."

**Dark mode**
"Add a dark theme using prefers-color-scheme with the app's dark surfaces #121214 and #1A1A1E. Keep contrast AA. Keep the hero phone in light theme."

**Hindi toggle**
"Add a simple English / Hindi toggle for the headings and button text only. Store the choice in a variable, no storage APIs."

**Deploy**
"Give me exact steps to host this free on GitHub Pages with the folder layout from the kit, including how to attach a custom domain."
